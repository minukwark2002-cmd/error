# Result image prompts (32)

How to use
1. For each type, paste **common style + scene** into your image AI (Midjourney, ChatGPT, Gemini, etc.).
2. Use a 9:16 aspect ratio, 1080×1920 or larger. Midjourney: add `--ar 9:16`.
3. Save the image as `img/<code>.jpg` (e.g. `img/01101.jpg`). The site places the text automatically.
4. To keep the series consistent, reuse the same style reference or seed when you regenerate.
5. Until a file exists, the site shows a color gradient for that type, so you can fill images in gradually.

cinematic film still, 35mm film grain, muted desaturated palette with a single deep red accent, melancholic yet serene, soft volumetric light, quiet and contemplative mood, vertical 9:16 composition, main subject in the upper half, lower third dark and empty, no text, no letters, no words, no watermark, no logo
